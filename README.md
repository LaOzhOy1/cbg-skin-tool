# 藏宝阁皮肤监控面板

本地跑的一个小服务，定时轮询《永劫无间》藏宝阁的公开接口，把当前在售的英雄皮肤/兵器皮肤列表展示在一个本地网页上。

## 边界说明（务必先读）

- **轮询阶段完全不用浏览器/不模拟点击**，就是纯 HTTP 请求 + 你自己账号的 Cookie，等同于你自己刷新网页看列表。
- **不做任何验证码自动识别/破解**。触发风控验证码或需要重新登录时，工具会打开一个真实、可见的浏览器窗口，人工在里面手动完成登录/验证码，工具只负责检测到成功后保存登录态，不代替你做任何点击。
- **不做自动下单**。商品卡片上的"查看详情"只是打开该商品的下单确认页链接，最终下单、支付密码/验证码都需要你本人操作。

如果你需要的是 7x24 无人值守自动抢购+自动支付，这个工具不支持，也不建议这么做——很可能违反藏宝阁使用条款并导致账号被限制。

## 安装

```bash
cd cbg-skin-tool
npm install
npx playwright install chromium
```

## 使用

### 1. 首次登录

```bash
npm run login
```

会打开一个可见浏览器窗口，手动完成网易通行证登录（扫码/短信/密码，验证码也由你本人操作）。检测到登录成功后自动保存登录态到 `storageState.json` 并关闭窗口。

### 2. 启动监控面板

```bash
npm start
```

终端会打印本地地址（默认 `http://localhost:4173`），用浏览器打开即可看到监控界面。

### 3. 页面里的验证提醒

轮询过程中如果遇到风控验证码或登录态失效，页面会弹出居中提醒弹窗，点"打开验证窗口"会在后台打开一个可见浏览器窗口，你在里面手动完成登录/验证码即可，工具检测到通过后会自动保存并恢复轮询。

## 已知限制（截至本次交付）

在实际调试过程中，账号先后遇到过 `CAPTCHA_AUTH`（图形验证码）、`AUTO_LOGIN`（会话需要刷新）、`MOBILE_AUTH`（要求短信验证手机号）三种风控状态。排查确认：

1. 触发 `CAPTCHA_AUTH` 的根本原因，是调试阶段短时间内对接口发了大量手动测试请求，被藏宝阁风控标记，**和用哪种技术实现（浏览器自动化还是纯 HTTP）无关**。
2. 中途还发现电脑当时挂着公司代理/VPN，出口 IP 是云服务器机房 IP（非家庭宽带/手机流量的正常消费级 IP），进一步降低了风控对这个会话的信任分。关闭代理换回正常宽带 IP 后，`CAPTCHA_AUTH` 那一关确实消失了。
3. 但风控评分继续升级到了 `MOBILE_AUTH`（要求短信验证手机号），这一步需要账号本人收验证码，本工具无法代为处理，需要你自己找个正常网络环境把账号验证完。

一旦账号验证通过、`storageState.json` 是干净可用的登录态，纯 HTTP 轮询本身已验证可以正常拉到数据（调试过程中用同样的 Cookie 直接 `fetch` 拿到过完整的 16 个英雄皮肤种类）。

## 已验证 / 未验证

**已验证：**
- 两层接口调用逻辑正确（`server/cbgClient.js`）：`/cgi/api/get_aggregate_equip_type_list` 拉皮肤种类列表，`POST /cgi-bin/recommend.py` 拉每个种类下的具体在售个体商品。用干净的登录态测试过，能正确拿到英雄皮肤 16 个种类的真实数据。
- 后端服务能正常启动、暴露 `/api/items`、`/api/status`、`/api/verify/*` 接口，`poller.js` 遇到风控/未登录会正确暂停轮询并切换状态，不会死循环乱发请求。
- 前端页面能正确渲染（用 mock 数据验证过卡片列表、状态面板、验证弹窗三种状态的 DOM 结构和文案都符合预期）。

**未验证（受限于当前账号验证状态，不是代码问题）：**
- 全流程"从触发验证码 → 打开验证窗口 → 人工完成 → 自动恢复轮询 → 页面看到真实数据"这条完整链路，还没能在一次干净的环境下走通到底。
- 页面在浏览器里的真实视觉效果（截图看起来正常，但建议你自己打开跑一遍确认字体、间距、动画细节符合预期）。

## 项目结构

```
cbg-skin-tool/
  server/
    index.js       # Express 入口：托管前端静态文件，挂载 API，启动轮询
    state.js        # 内存态：商品快照、轮询状态、验证流程状态
    cookieJar.js      # 读取 storageState.json 拼 Cookie 头
    cbgClient.js       # 纯 HTTP 版接口调用，识别 CAPTCHA_AUTH / AUTO_LOGIN / MOBILE_AUTH
    poller.js           # 定时轮询循环（默认 20 秒 ±20% 随机抖动）
    loginFlow.js          # 打开可见浏览器，等待人工登录/过验证码，保存登录态
  public/
    index.html            # 页面结构：左侧导航、商品卡片网格、右上状态面板、验证弹窗
    app.js                 # 前端逻辑：轮询状态/数据、渲染卡片、验证弹窗交互
    styles.css              # 莫兰迪暗色配色、磨砂玻璃卡片、悬浮动画等自定义样式
  src/
    session.js              # 登录态文件路径、isLoggedIn() 检测（登录流程复用）
    login.js                  # CLI 版首次登录脚本
    config.js                  # 分类 kindid/search_type 配置
  storageState.json          # 登录态（不提交到版本库）
```
